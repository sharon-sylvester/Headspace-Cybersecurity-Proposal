# Headspace Cybersecurity Proposal

## Project Overview
This collaborative team project developed a cybersecurity proposal for Headspace. The project focused on identifying cybersecurity risks and threats and developing recommendations to strengthen the organization's security posture.

This project was completed as part of my IBM cybersecurity training.

## Project Areas
- Cybersecurity risk and threat identification
- Asset and software inventory management
- Risk assessment and risk mitigation
- Multi-factor authentication (MFA)
- Access controls
- NIST and CIS security frameworks
- Employee cybersecurity awareness
- Phishing prevention
- Security alerts and monitoring
- Network and application security
- Incident response

## Security Recommendations
The team proposed security measures designed to reduce organizational risk, including:
- Maintaining accurate hardware and software inventories
- Strengthening authentication with MFA
- Implementing appropriate access controls
- Conducting cybersecurity risk assessments
- Applying established security frameworks such as NIST and CIS
- Providing employee cybersecurity awareness and phishing training
- Monitoring security alerts
- Strengthening network and application security
- Establishing protection, monitoring, and incident-response practices

- Cybersecurity research
- Security planning
- Security documentation
- Team collaboration and presentation
